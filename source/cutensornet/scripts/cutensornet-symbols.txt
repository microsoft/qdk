# The cuTensorNet functions this crate binds, one per row.
#
# scripts/generate-bindings.sh takes its bindgen allowlist from this file, and
# the crate's tests check that the rows of the cuTensorNet table in
# src/library/symbols.rs are exactly these. Widening the surface is a row
# here, the bindings regenerated, and the row added to the table by hand.
#
# Columns: <c_symbol>  <rust_field>  <required|optional>
#
# A `required` symbol's absence fails discovery; an `optional` one is `None`.
