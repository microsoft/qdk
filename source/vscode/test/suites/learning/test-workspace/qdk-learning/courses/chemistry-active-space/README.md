# Ground-State Molecular Energies with QPE

A port of the published QDK/Chemistry tutorial into the QDK Learning notebook course format.
The prose and code are carried over unchanged; only the container changes from Sphinx pages plus
standalone scripts to executable notebooks.

## Environment

Install the dependencies with:

    pip install -r requirements.txt

qdk-chemistry ships compiled binaries and is not available for native Windows. On Windows, open
this folder in WSL.
