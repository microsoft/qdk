# Ground-State Molecular Energies with QPE

The QDK/Chemistry ground-state QPE tutorial, as a QDK Learning notebook course.

## Environment

Install the dependencies with:

    pip install -r requirements.txt

qdk-chemistry ships compiled binaries for Linux, macOS on Apple silicon, and Windows on
x86-64. This course also needs PySCF, which has no Windows build, so run it inside WSL on
Windows.
