CodeProfile class

CodeProfile(code: qodec.Code)

Take a snapshot of a code, then inspect its algebra or search for logical errors.

  • encoding_clifford(*, supported_by=None)

  • representative_of(pauli)
  • is_equivalent_to(other, *, including_signs=True, strict_basis=True)
  • why_not_equivalent_to(other, *, including_signs=True, strict_basis=True)

length counts physical labels in support, not the largest label plus one. Operator collections are tuples of independent Pauli copies.

x[i] and z[i] are physical representatives for logical qubit i, following qodec's order. gauge_x[i] and gauge_z[i] form gauge pair i. These are read-only properties; X and Z describe their roles, not their physical Pauli factors.

is_logical requires zero syndrome and a nonidentity logical component; identity and gauge-only changes return false. logical_effect_of preserves phase by default and raises for detectable or gauge errors; use including_phase=False for their phase-free components.

distance finds the minimum number of allowed errors. Pass a string such as "XZ", or a sequence of explicit Pauli errors.

logical_observable=Pauli("Z_0") restricts failure to flipping logical Z on logical qubit zero. Observable indexes are logical; errors use physical labels. Invalid labels raise ValueError.

Build and complete qodecs

build_qodec function

build_qodec(
    code: qodec.Code | CodeProfile,
    *,
    name: str | None = None,
    description: str | None = None,
    strategy: str = "flagged-css/v1",
    strict: bool = True,
) -> qodec.Qodec

Build a two-layer qodec from a stabilizer code. The default strategy adds flag qubits. Use "bare-css/v1" to omit them.

With strict=True, an instruction that cannot be completed and verified raises instead of being omitted. Returned qodecs pass the default audit, but this does not prove fault tolerance.

filled(target: qodec.Gadget) -> qodec.Gadget

Return a new gadget or qodec with derived checks and observable readout bindings.

The input remains unchanged. Existing checks and observable equations can be recomputed. Flag bindings are preserved, not inferred.

Audit a complete qodec

audit function

audit(
    qodec: qodec.Qodec,
    *,
    disabled: Collection[str] = (),
    promote_warnings: bool = False,
) -> Report

Run every enabled audit rule. The report includes errors, warnings, and informational findings.

promote_warnings=True changes warnings into errors; it does not filter them out.

report = audit(qodec)

A Report contains all diagnostics. Each Diagnostic has rule, severity, summary, where, detail, and an optional source_location.

Severity values are Diagnostic.Severity.INFO, WARNING, and ERROR.

Results and values

Distance result class

Returned by profile distance searches; it cannot be constructed directly.

  • lower_bound, upper_bound — None means infinity
  • is_exact, value
  • witness — one finite upper-bound witness
  • witnesses — retained witness followed by lazy alternatives
  • Distance.Witness.factors, Distance.Witness.product

Comparisons use certified bounds and raise ValueError when the answer is unresolved. A witness exposes copied factors and their product.

FaultEvent class

FaultEvent(locations: Mapping[int, Pauli] | None = None)

FaultEvent.after(
    instruction: int,
    error: Pauli | None = None,
    *,
    readout_flips: int | Sequence[int] = (),
) -> FaultEvent

Describe a post-call Pauli error, a readout flip, or both. The instruction is a zero-based circuit-call index. Multiply events to combine them.

locations returns ordered snapshots; weight counts Pauli weight plus readout flips. Each FaultEvent.Location exposes after_call, error, and readout_flips.

FaultEffect class

FaultEffect(
    references: Iterable[qodec.ReferenceLike] = (),
)

Lists the checks, readouts, and output-frame signs changed by a fault. Its public properties are checks, readouts, and frames.

Effects support membership, iteration, length, and symmetric difference with ^.

ChannelAction result class

Returned by GadgetProfile.action and GadgetProfile.objective; it cannot be constructed directly.

  • is_equivalent_to(other, *, modulo_paulis=False)
  • why_not_equivalent_to(other)

Its text form shows observables, output stabilizers, and logical Pauli mappings. It is a readable display, not a canonical equivalence signature.

Pauli type alias

Pauli(characters=None, exponent=0)

An alias for paulimer.SparsePauli, used throughout qdk.ec. It has no members defined by qdk.ec; construction, algebra, formatting, and helpers such as Pauli.identity() come from paulimer.
